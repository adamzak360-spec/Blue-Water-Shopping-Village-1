COMMUNICATION AND SECURITY

Familiar communication,
accountable security

Product chat feels natural for customers and sellers, while receipts, unread counts, offline states, and sign-in alerts make the system accountable.

✓

✓✓

Delivered

✓✓

Read

Read styling changes when the recipient enters and views the conversation.

Unread awareness and new-device protection

Product chat buttons can show unseen-message counts. Offline messages expose a retry state. New-device sign-ins trigger security alerts so unusual access is visible early.

Design principle: familiar interactions should never reduce operational visibility or security accountability.
