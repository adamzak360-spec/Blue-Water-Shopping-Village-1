# Tizer workflow reference

The public Tizer pages were reviewed on 2026-11-15 to understand the user experience the Reliable Content Studio should approximate without copying branding or code.

Key workflow patterns observed:

- Start from an idea, prompt, script, footage upload, or a combination.
- Generate a structured short-form concept with hooks and a script.
- Connect narration, captions, visuals, pacing, and editing in one flow.
- Provide scene/timeline editing before export.
- Offer platform-oriented output for TikTok, Reels, Shorts, Facebook, and YouTube.
- Keep the workflow focused on reducing friction from idea to ready-to-post content.

Sources:

- https://tizer.video/ — public homepage describing auto-clipping, voiceovers, captions, timeline editing, AI video/image tools, and export.
- https://tizer.video/ai-video-creator — public AI video creator page describing idea/script/voice/visual/caption/export workflow.
- https://tizer.video/ai-script-generator — public script generator page describing hooks, outlines, short-form structure, and direct production handoff.

Reliable’s current free/self-hosted implementation uses the same broad flow—idea prompt, scene plan, captions, and export—but uses deterministic local generation and browser-rendered WebM instead of claiming cloud AI video or voiceover provider functionality that has not been configured.
